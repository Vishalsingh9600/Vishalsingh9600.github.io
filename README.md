# W. F. Vishal Singh — AI/ML Engineer Portfolio

Simple static HTML/CSS/JavaScript portfolio for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — responsive design and animations
- `script.js` — navigation, scroll animations, back-to-top and contact form
- `assets/` — copied public/project assets

## Run locally
Open `index.html` directly in a browser.

## GitHub Pages
Upload the contents of this folder to a public GitHub repository and enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
